# HISTORIA ART • FINE ART GALLERY & REPOSITORY
> **Museum-grade, Awwwards-caliber digital experience for Historia Art Gallery ([historiaart.com.ph](https://historiaart.com.ph)), established in 2015 in Metro Manila, Philippines.**

A bespoke digital institution built to bridge classical Philippine masterworks, contemporary sculpture, digital art, and collector jewelry with Swiss grid precision and architectural restraint.

## ⚡ Creative Technology Stack
* **Framework**: React 19, TypeScript, Vite
* **Smooth Scrolling**: Lenis (`duration: 1.2, easing: cubic-bezier`) synchronized with GSAP
* **Motion & Animation**: GSAP (`ScrollTrigger`, `quickTo` cursor kinematics)
* **Custom Cursor**: Adaptive high-contrast magnetic cursor dot with smooth examine pill morphing
* **Sound Design**: Pure Web Audio API synthesized ambient classical chord generator & real-time waveform equalizer
* **Styling**: Tailwind CSS (Warm Alabaster `#F6F4F0`, Obsidian `#121212`, Brushed Bronze `#8C7355`)

## 🖼️ Core Features & Pages
1. **Curated Masterworks & Catalogue Raisonné**:
   * Filterable categories: `All Works`, `Paintings`, `Sculptures`, `Digital Art`, `Collector's Jewelry`.
   * Uncropped high-definition museum framing with zero letterboxing.
2. **Museum Viewing Room Modal**:
   * Full-screen split-screen study with interactive zoom loupe and historical curatorial dossier.
   * Deep-linked `1:1 Gallery Scale View` featuring an architectural 170cm collector silhouette.
3. **Collector Acquisition Bag**:
   * Dedicated slide-over drawer with real-time portfolio valuation in PHP (`₱`).
   * Multi-rail settlement selector (Bank Wire / BPI Escrow, Credit Card, GCash / Maya, Curatorial Invoice).
4. **Curatorial Search Overlay (`⌘K`)**:
   * Instant live search indexing masterworks, artists, and exhibitions.
5. **Exhibitions & Manila Art Bulletin (`/exhibitions`)**:
   * Ongoing flagship spotlight (*Elevating Brilliance* celebrating 40 Filipino artists).
   * Chronological archive: *Bilog Ecosphere*, *The Heart of Home*, *Odyssey Reborn*, *Virtues*, *Because of Her*, *Ortigas Art Fair 2025*, *Visayas Art Fair 2025*, *TOPS Artfest 2026*.
6. **Master Artists Index**:
   * Canonical Masters (*Juan Luna*, *Fernando Amorsolo*, *Guillermo Tolentino*, *BenCab*, *Ramon Orlina*, *Romulo Olazo*).
   * Contemporary Roster (*Eman Santos*, *Windsor Magnaye*, *Marko Bello*, *Art Arreglado*, *Mari Zhar Carvill*, *Nilo Badajos*, *Darwin Peña*, *Sofia Martinez*).
7. **Institutional Heritage & Spaces (`/about`)**:
   * Full history, conservation standards (21°C / 50% RH), and interactive 3D Panorama Grand Salon walkthrough.
8. **Contact & Advisory Desk (`/contact`)**:
   * *"Ready to Start Your Next Artwork?"* advisory consultation form and hotlines (`0967-100-0468 | 0995-245-5840`).
9. **Institutional Governance & Policies**:
   * Full legal & policy modal covering Collector FAQs, Terms & Conditions, Privacy Policy, and Condition / Return Guarantees.

## 🚀 Getting Started

### Prerequisites
* Node.js 18+ or 20+
* npm

### Installation
```bash
# Clone the repository
git clone https://github.com/rimuelcodes/historiaart.git
cd historiaart

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
